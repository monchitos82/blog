There is no real use for a Readme here, this is my blog using GitHub pages. This blog has 2 formats, html for humans and md for LLMs.

This blog is built by hand. Every single line. Accessibility is an important consideration for this blog, even if you don't like the colors or the fonts, their primary objective is to be WCAG compliant and score above AA.

This blog is divided into Posts (long entries talking about a technical subject) and monthly entries (rants, comments, random thoughts). Entries might change over time or just be gone. I use a pipeline written in Jenkins (and leveraging Gemma over Ollama) to validate the content structure.
Most info will eventually be moved to the archive so expect the landing page to be plain.

This blog is the fourth iteration of it. It started here, on GitHub, eventually moving to Codeberg, then to NeoCities and finally coming back here. If you have not used [Codeberg](https://codeberg.org/), it is a great alternative for your repositories and [NeoCities](https://neocities.org/) is a great option for simple web pages.

Thanks for your visit.
